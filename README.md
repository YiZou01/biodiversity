# Summary

This dataset accompanies the article “Has biodiversity research become less field-based?” by Zou et al. (2026), published in *Frontiers in Ecology and the Environment*.

# Description

The archive contains six files.

## 1. `Dataset.csv`

Article-level data with classifications generated by a large language model (LLM). Article abstracts have been excluded because of Clarivate licensing restrictions.

The file contains the following columns:

- `WOS_id`: Web of Science accession number identifying the article.
- `Journal`: Name of the journal in which the article was published.
- `Publication_Year`: Year of publication.
- `Fieldwork`: LLM classification indicating whether the study is field-based. Values are “Yes”, “No”, or “Unclear”.
- `Primary_data`: LLM classification indicating whether the study is based on primary data. Values are “Yes”, “No”, or “Unclear”.

## 2. `Dataset_journal.csv`

Journal-level summaries containing the following columns:

- `Journal`: Journal name.
- `Field_no`: Number of articles classified by the LLM as “No” for fieldwork.
- `Field_unclear`: Number of articles classified by the LLM as “Unclear” for fieldwork.
- `Field_yes`: Number of articles classified by the LLM as “Yes” for fieldwork.
- `Primary_no`: Number of articles classified by the LLM as “No” for primary data.
- `Primary_unclear`: Number of articles classified by the LLM as “Unclear” for primary data.
- `Primary_yes`: Number of articles classified by the LLM as “Yes” for primary data.
- `Total`: Total number of articles.
- `X5_Year_JIF`: Five-year Journal Impact Factor.
- `X5_Year_JIF_Quartile`: Journal quartile based on the five-year Journal Impact Factor.

## 3. `Analysis.R`

R code used to analyze the data and generate the figures in the manuscript.

## 4. `Validation_samples.csv`

A sample of 200 articles used to validate the LLM classifications.

The file contains the following columns:

- `paper_id`: Web of Science accession number identifying the article.
- `Journal`: Name of the journal in which the article was published.
- `Publication.Year`: Year of publication.
- `source_file`: Source file from which the article record was obtained.
- `validation_id`: Identifier assigned to the article for validation.
- `abstract`: Article abstract.
- `fieldwork_h1`: Fieldwork classification from the first human assessment.
- `primary_data_h1`: Primary-data classification from the first human assessment.
- `fieldwork_h2`: Fieldwork classification from the second human assessment.
- `primary_data_h2`: Primary-data classification from the second human assessment.
- `final_fieldwork`: Final consensus classification for fieldwork.
- `final_primary_data`: Final consensus classification for primary data.
- `fieldwork_lmm`: LLM classification for fieldwork.
- `primary_data_lmm`: LLM classification for primary data.

All classification columns contain one of three values: “Yes”, “No”, or “Unclear”.

## 5. `LLM analysis.R`

R code used to classify the articles using the LLM.

## 6. `Prompt.R`

The prompt used for LLM classification in `LLM analysis.R`.
